# 调酒小程序架构文档

## 项目概览

这是一个基于微信小程序框架开发的调酒配方管理应用，主要功能包括配方展示、制作步骤指导、配方添加和单条自定义配方导入导出。

### 核心特性
- 📱 原生微信小程序
- 🍸 鸡尾酒配方管理
- 📝 分步骤制作指导
- 🔍 配方搜索功能
- ➕ 自定义配方添加
- 📤 单条自定义配方导入导出
- 🎨 现代化玻璃拟态UI设计

## 技术架构

### 技术栈
- **框架**: 微信小程序原生框架
- **样式**: WXSS (类CSS语法)
- **逻辑**: JavaScript ES6+
- **模板**: WXML (类HTML语法)
- **配置**: JSON配置文件

### 架构模式
- **MVC模式**: 页面级的Model-View-Controller架构
- **组件化**: 基于页面的组件化开发
- **数据驱动**: 使用setData进行数据绑定和视图更新

## 页面结构

### 底部 Tab
- 首页 (pages/index/index): 浏览、搜索和每日推荐
- 添加 (pages/add-cocktail/add-cocktail): 创建自定义配方；底部 Tab 显示为“添加 / 创建”
- 我的 (pages/mine/mine，待新增): 本机概览、自定义配方管理入口和导入入口；底部 Tab 显示为“我的 / 配方”

### 页面层级关系
```
主页 (index)
├── 配方详情页 (cocktail-detail)
│   └── 制作步骤页 (steps)
├── 添加配方页 (add-cocktail)
├── 编辑配方页 (edit-cocktail，待新增)
└── 我的页 (mine，待新增)
    ├── 自定义配方管理页 (custom-cocktails，待新增)
    └── 导入导出页 (import-export，待新增)
```

### 页面功能详解

#### 1. 主页 (pages/index/)
**功能**: 应用入口，展示配方列表和搜索功能
- **数据结构**:
  ```javascript
  {
    randomCocktail: Object,      // 每日推荐
    searchQuery: String,         // 搜索关键词
    cocktails: Array,           // 全部配方
    filteredCocktails: Array    // 过滤后的配方
  }
  ```
- **核心功能**:
  - 配方搜索和过滤
  - 配方列表展示
  - 导航到详情页和添加页
  - 每日推荐来自配方库，包含内置配方和当前设备上的自定义配方

#### 2. 配方详情页 (pages/cocktail-detail/)
**功能**: 展示单个配方的详细信息
- **数据结构**:
  ```javascript
  {
    cocktail: {
      name: String,        // 配方名称
      description: String, // 配方描述
      history: String,     // 内置配方历史背景
      source: String       // built-in 或 custom
    },
    steps: Array          // 制作步骤
  }
  ```
- **核心功能**:
  - 接收URL参数获取配方信息
  - 导航到制作步骤页
  - 详情页主操作只保留“开始制作”和“更多”
  - 自定义配方的编辑、删除和导出入口收纳在“更多”中；内置配方不显示这些管理操作
  - “更多”使用自定义底部操作面板，不使用原生操作菜单，以保持与当前深色主题和按钮风格一致
  - 不提供单条配方的微信原生分享；自定义配方跨设备传递只通过配方导出生成配方导入码
  - 内置配方有历史背景时展示历史背景区块；自定义配方当前不维护历史背景，不自动生成或展示伪历史背景

#### 3. 制作步骤页 (pages/steps/)
**功能**: 分步骤展示制作过程
- **数据结构**:
  ```javascript
  {
    steps: [{
      number: Number,      // 步骤编号
      instruction: String, // 步骤说明
      animation: String   // 动画类型
    }]
  }
  ```
- **核心功能**:
  - 步骤列表展示
  - 动画效果展示

#### 4. 添加配方页 (pages/add-cocktail/)
**功能**: 用户创建自定义配方
- **数据结构**:
  ```javascript
  {
    cocktailName: String,        // 配方名称
    cocktailDescription: String, // 配方描述
    steps: [{
      number: Number,
      instruction: String,
      animation: String
    }]
  }
  ```
- **核心功能**:
  - 填写并校验添加配方草稿
  - 动态步骤管理
  - 表单验证和保存
  - 简介在界面上允许不填，保存时空简介归一为“-”；非空简介最多 100 个字符
  - 制作时间可以留空并保存为“未设置”；页面应提示支持的时间格式，例如“10分钟、15min、1小时”
  - 新增自定义配方时，成分和制作步骤都最多 30 个
  - 成分每项不能为空、最多 20 个字符，且同一配方内不允许重复；制作步骤说明不能为空且每条最多 200 个字符
  - 配方图标是本机展示装饰，可以保存到自定义配方，但不会进入配方导入码
  - 用户离开新增页时，若已有输入内容且尚未保存，应二次确认；保存成功后的跳转不触发离开确认

#### 5. 编辑配方页 (pages/edit-cocktail/，待新增)
**功能**: 用户编辑既有自定义配方
- **核心功能**:
  - 从自定义配方详情页进入，并通过配方 ID 加载原自定义配方
  - 复用添加配方草稿的字段、校验和表单交互
  - 保存后更新原自定义配方，保留原配方 ID，刷新最近修改时间
  - 简介在界面上允许不填，保存时空简介归一为“-”；非空简介最多 100 个字符
  - 制作时间可以留空并保存为“未设置”；页面应提示支持的时间格式，例如“10分钟、15min、1小时”
  - 若原自定义配方的分类不在当前固定分类选项中，编辑页应临时加入该分类并设为当前选中，避免保存时静默覆盖
  - 编辑自定义配方时，成分和制作步骤都最多 30 个
  - 成分每项不能为空、最多 20 个字符，且同一配方内不允许重复；制作步骤说明不能为空且每条最多 200 个字符
  - 配方图标可以在本机编辑和保存，但不会进入配方导入码
  - 用户离开编辑页时，若当前表单内容相对加载时的原配方发生变化且尚未保存，应二次确认；未修改时直接离开

#### 6. 我的页 (pages/mine/，待新增)
**功能**: 本机个人空间，承载当前可用的本机概览、自定义配方管理入口和导入入口；当前不展示设置、数据管理、账号、头像、登录态或未登录提示
- **核心功能**:
  - 展示本机自定义配方总数等本地概览，不区分用户创建和导入来源
  - 提供配方导入入口
  - 提供自定义配方管理入口

#### 7. 自定义配方管理页 (pages/custom-cocktails/，待新增)
**功能**: 管理当前设备上的自定义配方，不管理内置配方
- **核心功能**:
  - 支持创建、查看、编辑、单条删除和批量删除自定义配方
  - 自定义配方管理列表默认按最近修改时间倒序展示，最后编辑的配方排在最前面
  - 自定义配方管理列表本次支持按最近修改时间和按名称排序；按名称排序使用本地化名称比较，不承诺严格拼音排序
  - 自定义配方管理列表支持搜索，搜索范围包括名称、简介、分类、难度和成分，但只搜索自定义配方；本次只做包含匹配并忽略英文大小写，不做拼音首字母、分词或模糊纠错
  - 自定义配方为空时展示空状态，并提供“添加配方”和“导入配方”入口
  - 浏览态下点击列表主体进入配方详情，每条自定义配方右侧提供“更多”入口，收纳编辑和删除
  - 批量删除采用购物车式管理模式：列表默认是浏览态，点击“管理”后进入多选态并显示复选框，支持全选/取消全选，底部显示“删除所选”操作
  - 批量管理态下隐藏单条“更多”入口，点击列表项切换选中状态
  - 批量管理态下搜索关键词变化或切换排序时清空当前选择；全选只作用于当前筛选后的可见列表
  - 批量删除确认弹窗只显示所选数量和不可恢复提示，不列出配方名称
  - 删除自定义配方前必须二次确认，删除后不提供回收站或恢复

#### 8. 导入导出页 (pages/import-export/，待新增)
**功能**: 单条自定义配方导入导出
- **数据结构**:
  ```javascript
  {
    mode: String,          // import 或 export
    importCode: String,     // 配方导入码
    importText: String,     // 用户粘贴的导入内容
    importPreview: Object,  // 校验后的导入预览
    targetName: String,     // 导入后名称
    error: String           // 导入导出错误提示
  }
  ```
- **核心功能**:
  - 同一页面根据入口切换导入和导出模式；带自定义配方 ID 进入导出模式，不带 ID 进入导入模式
  - 从自定义配方详情页进入后，将当前自定义配方导出为配方导入码
  - 内置配方不能导出；若误入导出模式，应提示用户当前配方不可导出
  - V1 配方导入码采用 `COCKTAIL_V1:<Base64(UTF-8 JSON)>` 编码，JSON 使用紧凑字符串和 `name`、`description`、`category`、`difficulty`、`time`、`ingredients`、`steps` 等可读字段名
  - V1 的 `ingredients` 使用字符串数组，`steps` 使用步骤对象数组；步骤对象当前只接收 `instruction` 字段，其他字段忽略
  - V1 必须包含 `name`、`description`、`category`、`difficulty`、`ingredients`、`steps`；`time` 可以缺省，缺省时按“未设置”处理
  - V1 导入时严格要求 `COCKTAIL_V1:` 前缀；必要字段按当前校验口径处理，额外字段忽略且不保存为自定义配方内容
  - V1 不承载配方图标等展示装饰；导入成功时按本机默认图标补齐
  - 以复制和粘贴文本的方式传递配方导入码
  - 导出后展示配方导入码，并提供复制按钮；导入码放入固定高度可滚动文本区域，默认约 280rpx，最大不超过当前视口高度约 30%，不随导入码长度撑开页面
  - 从我的页进入后，粘贴文本形式的配方导入码并校验
  - 解析导入文本时只忽略首尾空白和换行，不从大段普通文本中自动提取配方导入码
  - 导入时提供手动粘贴文本框和“从剪贴板读取”按钮；剪贴板读取成功后自动填入文本框并立即校验，合法时进入导入预览，不合法时保留文本框内容并显示错误
  - 剪贴板读取失败或未授权时保留手动粘贴兜底
  - 导入内容校验复用添加配方草稿校验口径，名称长度统一为 20 个字符，成分和步骤都最多 30 个；新增、编辑和导入使用同一套规模限制
  - 导入码中如果出现空成分、重复成分、空步骤或超长文本，应校验失败，不静默删除或截断
  - 难度只能是“简单”“中等”“困难”，导入码中的未知难度视为内容不合法
  - 分类是非空短文本，当前最多 10 个字符；导入码中的未知分类可以保存
  - 制作时间可以为空或为“未设置”，保存时空值统一归一为“未设置”；其他非空文本必须符合当前时间格式
  - 校验通过后展示导入预览，由用户确认后保存
  - 导入预览始终展示“导入后名称”输入框；未重名时默认原名称，重名时默认使用从“原名（2）”开始递增的第一个可用名称
  - 确认导入前重新校验导入后名称，确保名称合法且不重名
  - 导入码中的制作步骤只把步骤说明保存为当前配方内容，编号和动画由本机规则生成
  - 导入导出页不提供微信原生分享、小程序路径分享、二维码分享或云端链接

## 数据架构

### 全局数据 (app.js)
```javascript
globalData: {
  cocktails: [
    { name: String, description: String }
  ]
}
```

### 数据流向
1. **应用启动** → 全局数据初始化
2. **主页加载** → 从全局数据获取配方列表
3. **搜索操作** → 本地数据过滤
4. **页面跳转** → 通过配方 ID 优先传递配方身份，名称仅用于展示和兼容入口
5. **配方添加** → 添加配方草稿校验后保存为自定义配方，并通过本地存储持久化；新增成功后跳转到新配方详情页
6. **进入我的** → 用户从底部 Tab 进入本机个人空间，访问本机概览、自定义配方管理入口和配方导入入口
7. **配方编辑** → 通过编辑配方页加载自定义配方，复用添加配方草稿的字段、校验和表单交互，保存后在原自定义配方基础上更新，保留原配方 ID，刷新最近修改时间，成功后返回该配方详情页
8. **自定义配方管理** → 用户创建、查看、编辑、单条删除或批量删除当前设备上的自定义配方；新增、导入和编辑都不应产生与内置配方或自定义配方重名的配方，导入重名时建议递增名称，新增和编辑重名时提示用户修改，删除前必须二次确认；批量删除确认时显示所选数量；从详情页删除成功后统一跳转到自定义配方管理页，从列表删除后留在列表并刷新
9. **旧自定义配方迁移** → 自定义配方使用 `updatedAt` 记录最近修改时间；读取旧数据时若缺少 `updatedAt`，优先用 `createdAt` 补齐，若两者都缺失则生成当前时间，并写回本地存储
10. **配方导出** → 配方库把单条自定义配方转换为 `COCKTAIL_V1:<Base64(JSON)>` 格式的文本配方导入码
11. **配方导入** → 用户手动粘贴或从剪贴板读取文本配方导入码，按添加配方草稿的校验口径校验后生成导入预览
12. **确认导入** → 保存为当前设备上的自定义配方且不覆盖已有配方
13. **导入完成** → 跳转到新导入的自定义配方详情页，便于用户核对、制作或继续编辑
14. **微信原生分享** → 本次只保留首页的普通小程序分享；单条配方不通过微信原生分享、小程序路径、二维码或云端链接传递
15. **应用重启** → 配方库读取自定义配方并与内置配方合并

## 核心功能实现

### 1. 配方搜索
```javascript
onSearch(e) {
  const query = e.detail.value.toLowerCase();
  const filtered = this.data.cocktails.filter(cocktail => 
    cocktail.name.toLowerCase().includes(query) || 
    cocktail.description.toLowerCase().includes(query)
  );
  this.setData({ 
    searchQuery: query,
    filteredCocktails: filtered
  });
}
```

### 2. 页面导航
```javascript
// 带参数导航
navigateToCocktailDetail(e) {
  const name = e.currentTarget.dataset.name;
  wx.navigateTo({
    url: `/pages/cocktail-detail/cocktail-detail?name=${name}`
  });
}
```

### 3. 动态步骤管理
```javascript
addStep() {
  const newStep = { 
    number: this.data.steps.length + 1, 
    instruction: '', 
    animation: 'fadeIn'
  };
  this.setData({
    steps: [...this.data.steps, newStep]
  });
}
```

# 深化配方库 Module

状态：accepted

调酒配方小程序把内置配方、自定义配方保存、详情查询、制作步骤和跨设备传递数据分散在 App 与多个页面里，导致自定义配方只写不读、页面间用名称猜测配方身份、原分享页展示静态占位。我们决定引入配方库 Module 作为配方生命周期的主要 Interface，集中处理内置配方合并、自定义配方本地存储、配方 ID、搜索、每日推荐、制作步骤和配方跨设备传递数据；页面只负责展示、导航和微信 UI 交互。

## Consequences

配方相关页面应通过配方库读取和保存配方，不再直接维护自己的配方数据副本。未来接入云开发时，应把云端读写作为配方库背后的 Adapter，而不是让页面直接调用云能力。单条自定义配方的跨设备传递已在 ADR 0002 中收束为本地优先的配方导入导出。
